# Chouga 2.0

Plataforma digital da Chouga, marca de skate, streetwear e cultura urbana.

A Chouga 2.0 combina duas dimensões:

- Commerce;
- Culture.

Princípio de produto:

> Loja limpa. Conteúdo sujo. Engenharia limpa.

Princípio técnico:

> Compramos commodity. Construímos identidade.

## Status

Projeto em fase de fundação técnica e arquitetural.

O desenvolvimento da aplicação ainda não foi iniciado.

## Decisões atuais

- arquitetura em monólito modular;
- storefront próprio;
- Nuvemshop como Commerce Provider da V1;
- Next.js com App Router como framework do storefront;
- Commerce e Editorial desacoplados;
- integrações externas tratadas por adaptadores.
