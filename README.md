# CHOUGA SKATEBOARD V2.0 🛹

**Streetwear não se veste. Se vive.**

Storefront da Chouga Skateboard, marca independente conectada ao skate, à cultura urbana e à vida nas ruas.

## Tecnologias

Next.js, React, TypeScript e CSS Modules.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Validação

```bash
npm run lint
npm run typecheck
npm run build
```
